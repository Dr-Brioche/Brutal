# BRUTAL

Le jeu **Brutal** — version web.

## Où en est le projet ?

Pour l'instant : une première page (un écran de titre) pour avoir
quelque chose en ligne. Le jeu lui-même viendra ensuite, petit à petit.

## Comment voir la page ?

- **Sur l'ordinateur** : ouvrir le fichier `index.html` dans un navigateur.
- **En ligne** : la page est faite pour être hébergée gratuitement
  (GitHub Pages, Netlify…). Une seule page, aucun logiciel à installer.

## Les fichiers

| Fichier      | À quoi ça sert                                  |
|--------------|-------------------------------------------------|
| `index.html` | Toute la page : le texte, le style, le bouton.  |
| `README.md`  | Ce fichier : la « notice » du projet.           |
